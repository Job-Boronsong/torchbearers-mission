---
name: Strict Mode API retry tests
description: How React development-mode effect replay affects browser tests that simulate initial API failures.
---

When a browser test simulates an initial API outage in the Vite development build, it must fail every initial request generated by React's development-mode effect replay before allowing the visitor-triggered retry request to succeed.

**Why:** React development mode can mount, clean up, and remount effects, which creates more than one initial request. Failing only one can let the replayed request succeed and mask the error state the test is intended to verify.

**How to apply:** For an initial-load outage test, count or otherwise identify the automatic requests and only let the subsequent request made by the visible retry control continue to the backend.
